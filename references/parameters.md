# 参数与填槽手册

母版负责「怎么说」，本文件负责「填什么」。三个必填槽填对了，成图率从三成升到八成。

## 一、槽位一：核心主体名称

要求：**能一眼指认、且值得被保留的东西**。

| 题材 | 好填法 | 坏填法 |
|---|---|---|
| 人像 | 侧身回头的女性、坐在窗边的老人 | 人物、女孩 |
| 建筑 | 一扇半开的绿窗、拱形门廊 | 老房子 |
| 风景 | 一条伸入海中的栈桥、孤立的山脊线 | 海边风景 |
| 静物 | 一只斜放的瓷杯、半杯咖啡 | 桌面摆件 |
| 动物 | 背对镜头的猫、停在栏杆上的鸟 | 小动物 |

判断标准：**换成另一个人看这句话，能想象出同一个形状**。

## 二、槽位二：核心视觉结构

这是全流程最难的一步。要抽的不是「内容」，而是**可以被切下来、且切下后仍有轮廓辨识度的形态**。

从原图里找这三类：

1. **硬边界** —— 栏杆、窗框、桥、台阶、屋檐、电线、地平线
2. **轮廓明确的主体** —— 人形、船体、车顶、树冠、动物身形
3. **平面/层** —— 水面、墙面、雾层、光斑、织物褶皱

抽结构时问自己一句：**「如果沿这条线剪下来，剩下的那块还认得出是什么吗？」** 认不出就换。

## 三、槽位三：创意范式（三选一，不要混）

### 1. 主体切片式（slice）

- **形态**：沿主体轮廓或一条直线切下一片，立在纸面上，像一块竖起的厚卡纸。
- **适合**：人、船、车、房子、树、山脊。
- **关键句**：`相片物体为沿主体轮廓切下的片状实体，直立/斜倚于纸面，切口平直、可见纸芯分层`
- **易错**：切得太薄像贴纸 → 补「厚度约 2–3mm，切口有纤维毛边」。

### 2. 表层揭取式（peel）

- **形态**：把照片表面那一层像膜一样揭起来，一角翘起、悬空，背面是纸白色。
- **适合**：水面、墙面、天空、织物、雪地、路面。
- **关键句**：`相片物体为自原图表层揭起的一层薄片，左下角卷起并微微悬空，背面呈纸白色，投影落在纸面`
- **易错**：卷得太夸张变成飘带 → 补「卷曲半径约等于物体宽度的一半，形变克制」。

### 3. 空间穿孔式（hole）

- **形态**：纸面被切出一个洞（矩形/圆/门形），照片自洞中凸出成实体。
- **适合**：门廊、窗、隧道、镜面、拱、井口。
- **关键句**：`纸面被切出矩形孔洞，原图自孔洞中呈实体凸出约 5mm，孔缘可见纸芯厚度与轻微毛边`
- **易错**：洞后是另一张图/纯黑 → 补「孔洞内即为同一张照片的实体凸出，非另一画面」。

## 四、速写小人（0–3 个）

### 数量

| 数量 | 效果 | 建议 |
|---|---|---|
| 0 | 最克制，靠形变与阴影撑 | 物体本身足够有戏时用 |
| 1 | 最稳，视线集中 | **默认推荐** |
| 2 | 有叙事（推/拉/抬） | 物体较大时 |
| 3 | 上限，容易变插画 | 谨慎 |

### 动作库（必须是力学接触）

| 动作 | 适配范式 | 说明 |
|---|---|---|
| 单手掀起一角 | peel | 最经典，直接暴露「这是张纸」 |
| 双手推着物体前进 | slice / hole | 强调重量 |
| 从孔洞里探出半个身子 | hole | 强调「洞是真的」 |
| 坐在物体边缘、双腿垂下 | slice | 锚定厚度与尺度 |
| 拉住一根线把物体拽起 | 任意 | 需要额外一根炭黑细线，慎用 |
| 趴在纸面上、脸贴物体 | peel | 强调纸面是地面 |

禁止：挥手、跳跃、奔跑等「无接触动作」——会让小人变成装饰符号。

## 五、英文旁白

规则：**≤6 词、具象、不抒情、不用感叹号**。字号极小（约为画面高度 1.2–1.8%），深炭灰 `#3A3A38`，右下角，距边约画面宽 6–8%。

好的写法（写「物」或「动作」，不写「情」）：

```text
hold the light still
this corner of june
the sea, folded
a room that fits in hand
carry the morning
one step, still paper
```

坏的写法（陈词滥调 / 广告腔）：

```text
live your dream          ← 广告
every moment matters     ← 空泛
beautiful memories       ← 抒情
第二世界 · 摄影           ← 中文 + 标题感
```

## 六、纸张与配色

| 项 | 值 | 备注 |
|---|---|---|
| 纸色 | 暖米白 `#F4EFE4` ~ `#EFE8D9` | 不要纯白 `#FFF`，纯白会显廉价 |
| 纸纹 | 极细植物纤维，密度低 | 「极细腻」是关键词，纹重了像牛皮纸 |
| 斑点 | 极少、随机、直径 <2px 等效 | 克制 |
| 噪点 | 轻微印刷噪点，全图均匀 | 与上半区摄影噪点呼应 |
| 炭黑 | `#1C1C1A`，非纯黑 | 纯黑线条会抢主体 |
| 阴影 | 柔和、边缘羽化、透明度约 20–35% | 「无硬边」 |
| 留白 | 下半区实体占面 ≤40% | 超过就没有「留白场」了 |

## 七、填槽示例

### 例 1 · 人像

```bash
python3 scripts/build_prompt.py \
  --subject "侧身回头的女性" \
  --structure "她的侧脸轮廓与肩线" \
  --paradigm slice --figures 1 --caption "hold the light still"
```

### 例 2 · 建筑

```bash
python3 scripts/build_prompt.py \
  --subject "一扇半开的绿窗" \
  --structure "窗框的矩形与探出的绿植" \
  --paradigm hole --figures 1 --caption "a room that fits in hand"
```

### 例 3 · 风景

```bash
python3 scripts/build_prompt.py \
  --subject "伸入海中的栈桥" \
  --structure "栈桥的水平线与尽头的小屋" \
  --paradigm slice --figures 2 --caption "the sea, folded"
```

### 例 4 · 水面（最难的揭取式）

```bash
python3 scripts/build_prompt.py \
  --subject "傍晚反光的水面" \
  --structure "水面的一条反光带" \
  --paradigm peel --figures 0 --caption "carry the morning"
```

无小人版：靠卷边 + 投影 + 反光带本身的形状说服观众，成则极高级，败则像污渍——先试 `--figures 1` 再说。
