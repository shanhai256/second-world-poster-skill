# 母版提示词（逐字保留）

> 来源：小红书 **花谦汨** 公开分享（用户提供两张截图，本文件按原顺序拼接：截图 2 为前半段，截图 1 为后半段）。
> **以下为原文，不要改动。** 需要调整请写在 `variations.md`，或由 `scripts/build_prompt.py` 在槽位外追加。

## 原文

```text
请基于我上传的照片，生成一张竖版3:4的「第二世界」摄影二创海报，画面上下严格各占50%，
水平硬切分界，无可见分割线、无渐变过渡。

上半区（原生摄影场）需保留原始照片本体，仅做等比例居中裁切，100%保留原图的【核心主体
名称】、空间关系、自然光影、色彩层次与摄影质感，禁止重绘、插画化、调色、添加或删减元素。

下半区（物态留白场）的背景为暖米白哑光艺术纸，带极细腻植物纤维纹理、克制纸面斑点与轻微
印刷噪点，大面积留白为主动设计元素。从原图中提取【核心视觉结构】，将其转化为一块可触碰
的实体「相片物体」，采用【创意范式：主体切片式/表层揭取式/空间穿孔式】呈现。

「相片物体」硬性标准：
1. 表面完整保留原图的真实摄影纹理与色彩，无描边、无滤镜、无插画化修改
2. 具备明确纸张厚度，边缘可见清晰截面质感，存在自然力学形变（一角卷起、边缘弯折、
   整体微弧）
3. 与纸面形成明确接触关系，底部带有柔和接触阴影，阴影与上半区光源方向一致，透明自然
   无硬边
4. 主体身份完整可识别，形态与原图核心主体一一对应，仅改变物理形态，不改变结构、比例
   与核心特征

加入【数量：0-3个】极简炭黑速写小人，无五官无细节，仅保留动态轮廓，人物动作【具体互动
动作，能引起与照片景物的共鸣，如：单手掀起相片一角、双手推着相片物体或者其他】，动作与
图片中的景物引起共鸣，与相片物体形成明确力学互动，用于锚定物体尺度。在画面右下角添加
一句简短英文手写旁白，内容为「英文短句，不超过6个单词」，字号极小，深炭灰色，自然融入
纸面。字体美观不呆板，和画面不违和。

整体风格：真实摄影 + 暖米白纸张 + 极简黑线涂鸦 + 轻微手工拼贴感 + 独立杂志感，
干净克制，明亮有高级感。

严格禁止：整张图重绘插画化、下半区只有线稿无实体相片物体、发光描边特效、添加无关装饰
元素、商业广告感、厚重3D渲染、陈词滥调文案。
```

## 分层拆解

| 层 | 原文对应句 | 作用 |
|---|---|---|
| **版式** | 「竖版3:4」「上下严格各占50%」「水平硬切分界」 | 先把「形状」锁死，避免模型自由构图 |
| **否定三连** | 「无可见分割线、无渐变过渡」 | 模型默认会加分割线/渐变，必须显式堵住 |
| **分区命名** | 「原生摄影场」「物态留白场」 | 自造术语，给两半各自一个身份，比「上面/下面」稳得多 |
| **上半区保真** | 「仅做等比例居中裁切」「禁止重绘、插画化、调色」 | 一句允许 + 四个禁止，划定唯一合法操作 |
| **纸张质感** | 「暖米白哑光艺术纸」「植物纤维纹理」「印刷噪点」 | 把「纸」写成可渲染的材质，而非「背景色」 |
| **留白定位** | 「大面积留白为主动设计元素」 | 防模型把下半区填满，这是杂志感的核心 |
| **实体化** | 「可触碰的实体」「相片物体」 | 全篇关键动词：不是「放下」而是「转化为实体」 |
| **四条硬标** | 表面 → 厚度 → 接触 → 识别 | 按物理渲染顺序写，等于给模型一条管线 |
| **形态守恒** | 「仅改变物理形态，不改变结构、比例与核心特征」 | **最精妙的一句**：把「变形」与「重绘」切开，允许卷边但不许改脸 |
| **尺度锚** | 小人「用于锚定物体尺度」 | 说明小人的功能，模型才知道该画多大 |
| **旁白约束** | 「≤6个单词」「字号极小」「深炭灰色」 | 三重限制防它写成广告 Slogan |
| **风格收口** | 「真实摄影 + 暖米白纸张 + 极简黑线涂鸦 + …」 | 用加号串风格词，等价于一份配方 |
| **禁止清单** | 七条 | 每一条都对应一种真实翻车结果 |

## 为什么这条提示词有效

- **「硬切 + 无渐变」是对模型默认审美的正面抵抗**。扩散模型极爱在两块区域之间加柔和过渡，不写死就会糊成一片。
- **「仅改变物理形态，不改变结构、比例与核心特征」** 解决了二创海报最大的矛盾：既要「变成物」，又要「还是它」。这句话把允许的变换（物理形态）与禁止的变换（结构比例特征）显式分开。
- **四条硬标按物理顺序排列**（表面→厚度→接触→识别），读起来像渲染管线，比堆形容词更容易被遵循。
- **小人被赋予功能**（锚定尺度）而非装饰，模型因此会把它画成「参照物大小」，而不是「卡通人物」。
- **「陈词滥调文案」** 这种抽象否定，比列一堆禁用词更能逼出克制的旁白。

## 常见误读

- 「相片物体」不是「照片翻拍后贴在纸上」——它是**从原图里长出来的物**，表面与上半区同源。
- 「50/50」是**画面高度**的 50%，不是视觉重量的 50%。下半区留白多、实体小，视觉上是轻的，这才对。
- 「0 个小人」是合法选项。没有小人时，靠阴影和形变单独撑住「实体感」，更难，但更高级。
