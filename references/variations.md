# 变体

母版不动，变体是「改一条规则」。每条都标注了**改哪一句**，方便精确替换。

## 1. 4:5 / 1:1 版式

改：`竖版3:4` → `竖版4:5`（更适合小红书/Instagram 信息流）或 `正方形1:1`（适合封面）。

注意：改成 1:1 后，上下各 50% 仍成立，但下半区留白比例要下调到 35% 左右，否则显空。

## 2. 左右分割（不太推荐）

改：`画面上下严格各占50%，水平硬切分界` → `画面左右严格各占50%，垂直硬切分界`。

风险：人眼习惯左右阅读，左右分割会让「两个世界」变成「对比图」，隐喻弱一半。仅在原图是横构图、且主体偏一侧时使用。

## 3. 撕纸边（手工感 ×2）

追加在母版后：

> 分割处改为**手撕纸边**：上半区底缘呈不规则撕裂状，可见纸纤维毛刺与轻微翘起，撕口下方落下极淡的投影；仍不允许出现渐变或描边。

差异：手工拼贴感显著增强，但会削弱「硬切」的克制感。适合旅行、日记类题材。

## 4. 双色纸（低饱和版）

改：`暖米白哑光艺术纸` → `浅灰蓝哑光艺术纸（#DDE3E4）` 或 `淡赭色艺术纸（#E8DFCF）`。

差异：灰蓝配冷调照片（海、雨、冬），淡赭配暖调照片（午后、室内、老城）。纸色务必与照片主色**同族但更浅**，撞色就俗。

## 5. 多物体（2–3 块切片）

追加：

> 下半区自原图不同位置提取 **2–3 块**相片物体，各自独立成形、彼此不接触，大小与透视关系合理，共同构成一个松散的空间叙事；每块均需满足前述四条硬性标准。

差异：叙事性更强，但极易失控——三块以上必定变成拼贴画。

## 6. 圆形穿孔

改：`空间穿孔式` → `圆形穿孔式（孔径约为画面宽 35%）`。

差异：更像「镜头/月洞门」，适合建筑与夜景。圆孔边缘必须见纸芯厚度，否则会读成「蒙版」。

## 7. 纯线条版（向插画过渡）

追加：

> 下半区仅保留**炭黑速写线**勾勒的相片物体轮廓与关键结构线，不填色，不保留摄影纹理；上半区仍为完整原图。

差异：这是母版明确禁止的方向之一，作为**刻意变体**存在——当原图色调太杂、实体化后脏时，可以退到这一档保底。用之前先想清楚：它已经不是「第二世界」了，是「线稿注解版」。

## 8. 英文全量版（给 MJ / SD / Flux）

`build_prompt.py --lang en` 已输出英文母版，另可追加镜头语言：

```text
Shot as a flat-lay editorial page photographed straight on, soft north window light
from upper left, shallow paper texture visible, no lens distortion, no vignette.
```

## 9. 系列化（同一批图统一风格）

固定 `--paradigm`、`--figures`、纸色与旁白字体，只换 `--subject` / `--structure` / `--caption`。

一套 6–9 张，视觉上会形成强烈的「系列感」——这是这类海报最容易出效果的做法，比单张精修更划算。
